# TEC-01 · Ingeniería Web Hiperfluida: WebGL, Shaders de Cristal Líquido y Scrollytelling a 60 FPS

* **Publicación dual:** Editorial case study + Academy módulo TEC-01
* **Autoría:** Studio Brian Zuleta · Promii Engineering Lab

## Resumen
Pasar del blur plano CSS a óptica real (Fresnel, refracción RGB, tensión superficial en GPU) con Three.js + shaders GLSL + Lenis + GSAP, en menos de 180 KB.

## Lecciones
1. Del backdrop-filter al cristal líquido (Fresnel Schlick, dispersión Abbe, vertex displacement)
2. Scrollytelling de precisión (Lenis velocity + GSAP ScrollTrigger + exploded BIM view)
3. Gobernabilidad dual (ARCHITECTURAL_LIGHT / OBSIDIAN_LUXURY desde Stage Admin)
4. Micro-acústica procedural (Web Audio, mute by default) y presupuesto de rendimiento móvil

## Reto
Observar la portada promii.co, copiar prompts C.O.T.A. del estándar v4.0 y prototipar un hero interactivo.
